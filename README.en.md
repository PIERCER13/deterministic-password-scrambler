# Piercer Deterministic Password Scrambler

generate passwords determinísticas (PBKDF2 + SHA-256/512) a partir of password mestra + serviço without armazenar passwords

## Features

- **Main Sections**: generator Determinístico, Perfis of Serviços Salvos (without passwords)
- **Available Actions**: Derivar password, save Perfil of Serviço, Mostrar, copy
- **Auto-Save**: automatically persists changes in the browser (`localStorage`).
- **Multi-Language**: built-in language switcher (`PT / EN / ES`).

## How to Run

1. Run `start.bat` to start the local server on port `8151`, or open `index.html` directly in your browser.
2. Open `http://localhost:8151`.
