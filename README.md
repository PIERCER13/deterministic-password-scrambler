# Piercer Deterministic Password Scrambler

Gere senhas determinísticas (PBKDF2 + SHA-256/512) a partir de senha mestra + serviço sem armazenar senhas

## Funcionalidades

- **Seções principais**: Gerador Determinístico, Perfis de Serviços Salvos (Sem Senhas)
- **Ações disponíveis**: Derivar Senha, Salvar Perfil do Serviço, Mostrar, Copiar
- **Persistência automática**: salva alterações automaticamente no navegador (`localStorage`).
- **Multilíngue**: suporte integrado com botão de troca de idioma (`PT / EN / ES`).

## Como Executar

1. Execute `start.bat` para iniciar o servidor local na porta `8151`, ou abra `index.html` diretamente no navegador.
2. Acesse `http://localhost:8151`.
